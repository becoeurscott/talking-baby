# Project Roadmap — MY LITTLE LIFE

Each milestone needs explicit approval (`APPROVED` / `MILESTONE ACCEPTED` / `MOVE TO NEXT MILESTONE`) before the next one starts.

## Phase A — First Playable (Baby stage)
| # | Milestone | Deliverable |
|---|---|---|
| M0 | Project foundation & documentation | CLAUDE.md + `Documentation/` set |
| M1 | Unity 6 LTS URP project + Git/GitHub | Empty project opens; Web build runs in browser; first commit pushed |
| M2 | Baby character concept + prototype model import | Original baby concept approved; model (PROTOTYPE) imported with materials |
| M3 | Rig, Animator, idle / blink / smile | Baby breathes, blinks, smiles in editor |
| M4 | Bedroom / nursery environment | Lit URP room with interactable objects placed |
| M5 | Touch interaction + reactions | Tap/tickle/cheek touch triggers reactions; eye follows touch |
| M6 | Needs system + feeding & sleeping | Hunger/energy etc. decay; bottle and bed work; crying when hungry |
| M7 | First mobile UI | Status display + Feed/Play/Sleep actions + nav shell |
| M8 | Save system | Auto-save/load JSON, versioned, backup |
| M9 | Native Android/iOS device build, voice reactions, polish | Runs smoothly on a real phone; passes First Playable checklist |
